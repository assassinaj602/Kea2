# u2_flutter

Flutter driver plugin for `uiautomator2` enabling widget-level interaction and automated testing for Flutter and hybrid Android apps.

## 🛠️ Status: ✅ Active - Official Plugin (Pending)

[![uiautomator2](https://img.shields.io/badge/uiautomator2-plugin-blue)](https://github.com/openatx/uiautomator2)

## Overview

`u2_flutter` extends `uiautomator2` with Flutter Dart VM Service protocol integration, allowing seamless element finding by key, text, tooltip, type, and Semantics, as well as native + Flutter hybrid interaction support.
